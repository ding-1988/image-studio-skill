Model-ready

GPT Image 2.5 模型与设置

CLI 会把 --model 原样发送给配置的 OpenAI-compatible Images API。先检查服务商实际开放的模型，再选择速度、质量或兼容性入口。

gpt-image-2.5-flare

速度优先，适合日常文生图、图生图和快速编辑。建议从 --quality medium 或 --quality high 开始，需要更高质量时再尝试 xhigh 或 max。

gpt-image-2.5-sunburst

质量和编辑精度优先，适合复杂构图、细节控制和主体保持。建议使用 --quality high、xhigh 或 max。

gpt-image-2.5

GPT Image 2.5 兼容入口。它是否存在以及支持哪些参数由当前服务商决定，使用前请运行 image-studio models --json。

常用设置

GPT Image 2.5 服务通常支持 auto|low|medium|high|xhigh|max 质量、auto 或 1024x1024 / 1536x1024 / 1024x1536 尺寸，以及 PNG、JPEG、WebP 和透明背景。兼容服务可能只开放其中一部分。

image-studio models --json
image-studio generate --model gpt-image-2.5-flare --quality high --size 1024x1024 --prompt "速度优先的日常产品图" --output ./outputs/
image-studio generate --model gpt-image-2.5-sunburst --quality xhigh --size 1536x1024 --prompt "复杂场景，保持主体细节" --output ./outputs/
image-studio config set --model gpt-image-2.5-flare
How it works

安装器只做三件事

流程透明、可重复执行，安装完成后自动检查实际文件，而不是只相信命令退出码。

1

检查运行环境

确认 Node.js 20+ 与 npm 可用；缺少时使用系统支持的用户可控方式安装当前 LTS。

2

安装 CLI 与 Skill

从公共 npm 包安装 Image-studio，再写入 Codex 的用户级 Skills 目录。

3

执行真实验证

运行 CLI 帮助并检查 SKILL.md 是否存在，最后报告准确安装路径。
